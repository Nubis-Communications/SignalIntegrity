# On-line Video Examples

The updated page of on-line video examples is [HERE](https://github.com/TeledyneLeCroy/SignalIntegrity/wiki/Video-Examples).

Currently, there are two on-line video examples that demonstrate some of the usage of ***SignalIntegrity***:

1.  [Mixed-mode s-parameter generation](http://nubis-communications.github.io/SignalIntegrity/Videos/MixedMode.mp4) - In this example video, a four-port differential s-parameter block is converted to mixed-mode s-parameters using mode converters. This example shows generally also how systems of interconnected s-parameter blocks can be created in the schematic editor and how the s-parameters of the interconnected system can be generated.

2.  [TDR Simulation](http://nubis-communications.github.io/SignalIntegrity/Videos/TDRSimulation.mp4) - In this example video, a TDR simulation is performed with a mismatched transmission line. This example shows generally how sources and circuit elements are interconnected along with probes and time-domain simulations performed. Additionally, it’s educational regarding TDR, mismatched lines, and forward and reverse wave propagation.

They are slightly outdated, but convey proper information. Note that originally, the tool was called PySI - user’s should note the change in name to SignalIntegrity.

The intent is to update them and add more of them.

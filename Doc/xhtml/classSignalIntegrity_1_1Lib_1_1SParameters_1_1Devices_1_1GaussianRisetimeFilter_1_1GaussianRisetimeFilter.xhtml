Detailed Description

Gaussian COM based FIR filter that, when convolved with step, provides the risetime specified at the given sample rate.

Parameters
rtfloat risetime desired.
Fsfloat sample rate
is1090boolean (optional, defaults to True) whether 10-90 risetime is specified. Otherwise 20-80 risetime is used.
Z0float (optional, defaults to 50) reference impedance

The s-parameters are for a two-port device that is "amplifier-like", meaning it has infinite input impedance, zero output impedance, the impulse response forms s21, and has infinite reverse isolation.

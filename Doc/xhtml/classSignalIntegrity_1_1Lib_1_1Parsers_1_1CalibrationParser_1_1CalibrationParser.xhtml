protected

processes a line of a netlist, handing calibration specific commands.


Lines that can be processed at this level are processed and lines that are unknown are place in a list of unknown lines for upstream processing. This enables derived classes to benefit from what this class knows how to process and to simply add specific functionality. As a simple example, a derived simulator class needs to add output probes, and this simple system description class knows nothing of this.
netlist lines that are handled at this level are:

  • 'calibration' - handling of calibration measurements

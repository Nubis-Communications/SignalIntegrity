45 Reads the s-parameter file and produces an instance of its base class SParameters.
46
47 If the reference impedance of the Touchstone 1.0 file read is not the reference
48 impedance specified, then the reference impedance of the s-parameters are converted
49 to the reference impedance specified.
50
51 The callback function is used to pass down into s-parameter files that are actually
52 SignalIntegrity projects so that progress can be tracked and the UI thread can be kept
53 updated. The callback function should have a signature like Callback(self,number,name=None),
54 where the number is the progress in percent and the name is the name of the file being processed.
55
56 If the name is the name of an s-parameter file and one of the kwarg keywords is 'text', then
57 the item associated with the keyword is assumed be a text stream containing s-parameter data to
58 directly fill in. In this case, the file name is used only to determine the number of ports.
59
60 if a kwarg keyword is 'reorder', then it is followed by a string of comma separted integer
61 one-based values representing the ports to take the data from in the list. For example, a
62 two-port with the argument 'reorder 1,2' will return the s-parameters unchanged, but
63 'reorder 2,1' will swap the ports. You can also use 'reorder 1' to extract the port 1 return
64 loss and convert it into a one-port s-parameter.
65 """

22class NoiseAnalysis(dict):
23 """Computes and organizes the results of a linear noise analysis.
24 Given a set of noise sources (inputs), the transfer functions from those
25 sources to a set of observation points (outputs), and the ideal signal
26 waveforms at those outputs, this class propagates each input noise spectral
27 density to every output, sums the contributions, and derives a collection
28 of summary metrics (rms, dBm, spectral densities, and signal-to-noise
29 ratios).
30
31 The class subclasses ``dict``; all results are stored as keys on the
32 instance. Every input and output may be designated as either a
33 ``'voltage'`` or a ``'current'`` quantity via the ``input_types`` and
34 ``output_types`` arguments. The declared type selects the neutral rms
35 interpretation ('rms' is a voltage rms in volts or a current rms in amps)
36 and the power law used when converting to dBm (P = V**2/R for voltages,
37 P = I**2*R for currents).
38
39 The following keys are populated on the instance (all dictionaries are
40 keyed by the corresponding input or output name unless noted):
41
42 - ``'output_names'`` / ``'input_names'``: the ordered name lists.
43 - ``'output_types'`` / ``'input_types'``: the name-to-type maps.
44 - ``'transfer_matrices'``: the transfer matrices passed in.
45 - ``'input_noise_spectral_density_list'``: list of input spectral
46 densities (in the input order).
47 - ``'input_noise_spectral_density'``: per-input dict with keys
48 ``'spectrum'``, ``'type'``, ``'dBm'`` and ``'rms'``.
49 - ``'output_noise_spectral_density_list'``: list of total output noise
50 spectral densities (in the output order).
51 - ``'output_noise_spectral_density'``: per-output dict with keys
52 ``'spectrum'``, ``'type'``, ``'dBm'``, ``'rms'``, and the frequency
53 normalized values ``'rms/sqrt(Hz)'``, ``'rms/sqrt(GHz)'``,
54 ``'dBm/Hz'`` and ``'dBm/GHz'``.
55 - ``'signal_noise_spectral_density_list'`` /
56 ``'signal_noise_spectral_density'``: the spectral density of the ideal
57 signal at each output (used as the reference for SNR calculations).
58 - ``'signal_to_noise_ratio'``: per-output dict with ``'SNR'`` and
59 ``'SalzSNR'`` in dB.
60 - ``'contributions'``: per-output, per-input dict giving the individual
61 noise contribution of each input to each output, with keys
62 ``'spectrum'``, ``'type'``, ``'dBm'``, ``'rms'``, ``'SNR'`` and
63 ``'SalzSNR'``.
64 """
65

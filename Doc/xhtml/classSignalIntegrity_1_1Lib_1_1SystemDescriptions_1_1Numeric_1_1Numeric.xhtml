Special computation of \(\mathbf{A}^\dagger\) where \(\mathbf{L}\cdot\mathbf{A}^\dagger\cdot\mathbf{R}\) needs to be computed
.

Parameters
Amatrix \(\mathbf{A}\) to be inverted
Leftoptional matrix that appears to the left of \(\mathbf{A}^\dagger\)
Rightoptional matrix that appears to the right of \(\mathbf{A}^\dagger\)
Mul(optional) whether to provide the result \(\mathbf{L}\cdot\mathbf{A}^\dagger\cdot\mathbf{R}\). Otherwise, by default, $A^\dagger\f$ is returned.
Returns
matrix \(\mathbf{A}^\dagger\)
Exceptions
LinAlgErrorif matrix cannot be inverted
Remarks
All matrices supplied can be either list of list or numpy matrix, but the return type is always a numpy matrix

if trySVD if False and alwaysUseSVD is False, then the Left and Right arguments are ignored and an attempt is made at calculating the Moore-Penrose pseudo-inverse of \(\mathbf{A}\). if the condition number of the resulting inverse is less than the conditionNumberLimit, then this method fails.
If alwaysUseSVD is True or there is a failure and trySVD is True, then the svd is used. The svd is not _better_ than the pseudo-inverse, per se, but it is able to make use of the left and right matrices.
Many of the problems are of the form \(\mathbf{L}\cdot\mathbf{A}^{-1}\cdot\mathbf{R}\). In many cases, the matrices \(\mathbf{L}\) and/or \(\mathbf{R}\) are such that the all of the elements of the inverse of \(\mathbf{A}\) are not used. Usually, in this case, \(\Sigma\) contains some zero values. The left and right matrices are used to see whether the inverse of the zero singular value would be selected. If both a column of the left matrix and a row of the right matrix both contain zeros such that they don't select the singular value, it can be removed and does not affect the answer. If either the left or the right matrix don't select the element, then allowing the solution allows for possible, non-unique values to be generated.

See also
allowPossibleNonUniqueSolutions Think of it as we only want to find certain elements of the inverse. Situations like this arise, for example, when we have two wires in parallel connected to two circuit nodes. We are not able to calculate the current through each of the wires, but we are able to calculate the current into and out of the parallel combination. Another example is a circuit with no ground reference provided and we are calculating the differential voltage across an element in the circuit. In cases like this, it is not possible to calculate the values of each circuit node, yet the answer exists and can be found.
Using the svd, \(\mathbf{A}\) is decomposed into \(\mathbf{U}\cdot diag\left(\sigma\right)\cdot\mathbf{V}^H\) where if \(\mathbf{U}\) is \(R\times C\), \(diag\left(\sigma\right)\) is \(C\times C\) and \(\mathbf{V}\) is \(C\times C\). The inverse of \(\mathbf{A}\) can be written as \(\mathbf{V}\cdot diag\left(\sigma\right)^{-1}\cdot\mathbf{U}^H\).
Here, we multiply the matrix \(\mathbf{L}\cdot\mathbf{V}\) and the matrix \(\mathbf{U}^H\cdot\mathbf{R}\). Then, if a column \(rc\) of \(\mathbf{L}\cdot\mathbf{V}\) is all zeros or a row \(rc\) of \(\mathbf{U}^H\cdot\mathbf{R}\) is zero, we know that the singular value \(\sigma\left[rc\right]\) is not used and is irrelevant - we set it to one so that it can't harm us and return the inverse.

◆ alwaysUseSVD

alwaysUseSVD = False
static

whether to always us the svd for matrix inverse computation.

The default is False meaning that it first tries the numpy getI() for the moore-penrose pseudo-inverse. If this fails or the condition number is poor, it will try again using svd if trySVD is True.

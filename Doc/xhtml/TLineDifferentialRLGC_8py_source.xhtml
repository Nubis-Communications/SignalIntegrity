49 @param Gm float mutual conductance (S)

52 @param K (optional) integer number of sections (defaults to zero)
53 @param scale (optional) float amount to scale the line by (assuming all other values are per unit)

56 TLineDifferentialRLGCApproximate, unless the number provided is zero (the default).\n
57
58 If zero is specified, then tests will be made
59 for the appropriate analytic model to use according to the following table:
60
61 | uncoupled | balanced | Model |
62 |:--------: |:--------:|:---------------------------------------------------|
63 | True | X | TLineDifferentialRLGCUncoupled |
64 | False | True | TLineDifferentialRLGCBalanced |
65 | False | False | TLineDifferentialRLGCApproximate |
66
67 If, because of imbalance and coupling, the approximate model must be used, the number of
68 sections changed from K=0 specified to a value that will provided a very good numerical
69 approximation.
70
71 The calculation is such that round-trip propagation time (twice the electrical length)
72 of any one small section is no more than one percent of the fastest possible risetime.
73 """
